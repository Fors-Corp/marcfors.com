# Selected work

## Embedded RAG
Classic RAG: one pgvector search, then one Claude answer with citations — or a fixed abstain when the corpus does not support the question. Python and Vercel/Neon share MiniLM embeddings and the same grounding rules. Live demo; public source.
Stack: Python, React, TypeScript, Neon, Claude API.
Live: https://embedded-rag.vercel.app
Repo: https://github.com/Fors-Corp/embedded-rag
Case study: /work/embedded-rag

## Wordkeep
A language app that teaches seven languages by playing, keeps a personal lexicon from Wiktionary with spaced review, and has Claude break whole phrases down grammatically. Words link across languages in a 3D atlas. Your lexicon stays on the device; optional accounts are end-to-end encrypted. App Store release pending.
Stack: React, TypeScript, Three.js, Hono, Claude API.
Live: https://wordkeep.me
Case study: /work/wordkeep
Private source.

## Fors Photography
Marc’s print shop on forsphoto.com: 18 signed fine-art prints in four collections, from the Pacific coast, the desert Southwest and Europe, printed to order in four sizes. Six languages, Stripe-hosted checkout, no database, accounts or analytics.
Stack: Next.js 16, React 19, Tailwind CSS, Stripe.
Live: https://www.forsphoto.com
Case study: /work/fors-photography
Private source.

## Mensura
A private, single-user on-device tracker with a self-made ML model that auto-learns an hourly forecast from the user’s own logs. Timing, recency, amount and cross-log patterns are modelled on-device; forecasts are tested against held-out history. Logs stay in the browser.
Stack: Vite, React, TypeScript.
Live: https://mensura.cc
Case study: /work/mensura
Private source.

## marcfors.com
This atlas. Semantic portfolio with first-party vitals, a supply-chain audit on every build, and seven locales. Public source. Includes an Ask page that answers portfolio questions with Embedded RAG grounding.
Stack: Next.js 16, React 19, TypeScript.
Live: https://marcfors.com
Repo: https://github.com/Fors-Corp/marcfors.com
Case study: /work/marcfors-com

## Gatto
A live, trilingual storefront for Silvia Galiano's handicraft shop in Gràcia, Barcelona. Spanish, Catalan and English; directions, opening hours and direct contact, without dependencies or trackers.
Case study: /work/gatto
