# Agent Switchboard

## Problem

Running many agent sessions across Claude, Codex, Cursor and Grok made it hard to see last prompts, dirty git trees, deployment health and secrets in one place.

## Approach

A local React and Express ops desk with a Swift macOS menu extra: last prompt, git dirt, Vercel health checks and an encrypted env vault stay on the machine.

## Result

A private instrument for day-to-day agent ops, not a hosted product — source stays private.
