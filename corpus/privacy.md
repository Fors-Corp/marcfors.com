# Privacy

marcfors.com is published by Marc Fors, a self-employed software engineer based in Barcelona, Spain, working under the name Fors Corp. You can reach him at developer@marcfors.com. There is no phone number on the site.

The site does not use advertising or cross-site tracking. There is no Google Analytics and no social-media pixels. Host Web Analytics (Vercel) is disclosed on the privacy page. One cookie, marcfors-locale, is written only when a visitor picks a language. Language and theme choices also stay in the browser's localStorage. There is no cookie banner, because those preferences are not tracking cookies.

Ask, at https://marcfors.com/ask, posts the question to this site. The server retrieves chunks from a Neon Postgres index of this portfolio corpus and sends the retrieved context plus the question to Anthropic's Claude API. Neon stores the pre-seeded corpus, not the visitor's questions. Do not paste secrets into Ask.

The public privacy notice is at https://marcfors.com/privacy. Requests to access, correct or erase personal data go to developer@marcfors.com.
