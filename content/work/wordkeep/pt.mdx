## Problema

Uma lista de cartões diz-te que palavras guardaste, não como se relacionam. Aprendes 'hot' e 'cold' como duas entradas soltas em vez de um eixo que já intuis em quatro línguas.

## Abordagem

Cada palavra guardada leva ligações tipadas — sinónimo, antónimo, tradução, relacionada. Uma fila espaçada agenda a revisão; um grafo de forças 3D, o Atlas, dispõe todo o léxico para que essas ligações ganhem forma. React, Vite e uma pequena API serverless.

## Resultado

Um vocabulário pelo qual podes caminhar, não só fazer scroll. O Atlas desta página é uma fatia congelada do grafo ao vivo; a versão 3D completa está a um clique.
