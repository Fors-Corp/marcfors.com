## Problema

Cada produto Fors reinventava botões, temas e primitivas de acessibilidade em vez de partilhar uma biblioteca auditada.

## Abordagem

O Fors Design System empacota tokens de marca e 30 componentes React sobre Radix com tema claro/escuro, WCAG 2.1 AA, RTL, e publica-os no GitHub Packages com um site de documentação público.

## Resultado

Uma base partilhada por trás dos produtos que publico, com código público e uma galeria de componentes alojada.
