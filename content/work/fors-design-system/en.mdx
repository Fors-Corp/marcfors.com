## Problem

Every Fors product was reinventing buttons, themes and accessibility primitives instead of sharing one audited library.

## Approach

The Fors Design System packages brand tokens and 30 Radix-backed React components with dark/light theming, WCAG 2.1 AA, RTL support, and publishes them to GitHub Packages with a public docs site.

## Result

A shared foundation behind the products I ship, with public source and a hosted component gallery.
