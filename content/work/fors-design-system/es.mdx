## Problema

Cada producto Fors reinventaba botones, temas y primitivas de accesibilidad en lugar de compartir una librería auditada.

## Enfoque

El Fors Design System empaqueta tokens de marca y 30 componentes React sobre Radix con tema claro/oscuro, WCAG 2.1 AA, RTL, y los publica en GitHub Packages con un sitio de documentación público.

## Resultado

Una base compartida detrás de los productos que publico, con código público y una galería de componentes alojada.
