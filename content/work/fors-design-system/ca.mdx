## Problema

Cada producte Fors reinventava botons, temes i primitives d'accessibilitat en lloc de compartir una llibreria auditada.

## Enfocament

El Fors Design System empaqueta tokens de marca i 30 components React sobre Radix amb tema clar/fosc, WCAG 2.1 AA, RTL, i els publica a GitHub Packages amb un lloc de documentació públic.

## Resultat

Una base compartida darrere dels productes que publico, amb codi públic i una galeria de components allotjada.
