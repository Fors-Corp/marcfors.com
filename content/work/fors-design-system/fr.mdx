## Problème

Chaque produit Fors réinventait boutons, thèmes et primitives d’accessibilité au lieu de partager une bibliothèque auditée.

## Approche

Le Fors Design System empaquette tokens de marque et 30 composants React fondés sur Radix avec thèmes clair/sombre, WCAG 2.1 AA, RTL, et les publie sur GitHub Packages avec un site de documentation public.

## Résultat

Une base partagée derrière les produits que je livre, avec code source public et une galerie de composants hébergée.
