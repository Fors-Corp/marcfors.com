## Problema

Volia un stack d'observabilitat versionable com dos artefactes des d'un mateix arbre: l'agent que recull i serveix, i la llibreria React amb què es pinta.

## Enfocament

forsight publica un agent Go que recull mètriques, serveix una API HTTP i incrusta el seu propi panell, amb detecció d'anomalies i previsions per ML, junt amb la llibreria de components React. El lloc Pages públic és la demo.

## Resultat

Un instrument d'observabilitat viu amb demo pública i codi privat.
