## Problema

Queria um stack de observabilidade versionável como dois artefactos a partir da mesma árvore: o agente que recolhe e serve, e a biblioteca React com que se desenha.

## Abordagem

forsight publica um agente Go que recolhe métricas, serve uma API HTTP e incorpora o seu próprio painel, com deteção de anomalias e previsões por ML, juntamente com a biblioteca de componentes React. O site Pages público é a demo.

## Resultado

Um instrumento de observabilidade vivo com demo pública e código privado.
