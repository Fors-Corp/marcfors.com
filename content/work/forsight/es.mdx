## Problema

Quería un stack de observabilidad versionable como dos artefactos desde un mismo árbol: el agente que recoge y sirve, y la librería React con la que se pinta.

## Enfoque

forsight publica un agente Go que recoge métricas, sirve una API HTTP e incrusta su propio panel, con detección de anomalías y previsiones por ML, junto a la librería de componentes React. El sitio Pages público es la demo.

## Resultado

Un instrumento de observabilidad vivo con demo pública y código privado.
