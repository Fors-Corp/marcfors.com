## Problema

Gestionar muchas sesiones de agentes entre Claude, Codex, Cursor y Grok dificultaba ver últimos prompts, árboles git sucios, salud de despliegues y secretos en un solo sitio.

## Enfoque

Una mesa de operaciones local en React y Express con un extra de menú Swift en macOS: último prompt, git sucio, salud de Vercel y una bóveda de env cifrada permanecen en la máquina.

## Resultado

Un instrumento privado para la operativa diaria de agentes, no un producto alojado — el código sigue en privado.
