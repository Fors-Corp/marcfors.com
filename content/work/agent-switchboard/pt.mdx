## Problema

Gerir muitas sessões de agentes entre Claude, Codex, Cursor e Grok dificultava ver últimos prompts, árvores git sujas, saúde de deploys e segredos num só sítio.

## Abordagem

Uma mesa de operações local em React e Express com um extra de menu Swift no macOS: último prompt, git sujo, saúde Vercel e um cofre de env cifrado ficam na máquina.

## Resultado

Um instrumento privado para a operação diária de agentes, não um produto alojado — o código permanece privado.
