## Problème

Gérer beaucoup de sessions d’agents entre Claude, Codex, Cursor et Grok rendait difficile de voir derniers prompts, arbres git sales, santé des déploiements et secrets au même endroit.

## Approche

Un bureau d’exploitation local en React et Express avec un extra de barre de menus Swift sur macOS : dernier prompt, git sale, santé Vercel et un coffre d’env chiffré restent sur la machine.

## Résultat

Un instrument privé pour l’exploitation quotidienne des agents, pas un produit hébergé — le code reste privé.
