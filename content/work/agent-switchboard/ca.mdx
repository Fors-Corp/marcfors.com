## Problema

Gestionar moltes sessions d'agents entre Claude, Codex, Cursor i Grok dificultava veure darrers prompts, arbres git bruts, salut de desplegaments i secrets en un sol lloc.

## Enfocament

Una taula d'operacions local en React i Express amb un extra de menú Swift a macOS: darrer prompt, git brut, salut de Vercel i una volta d'env xifrada es queden a la màquina.

## Resultat

Un instrument privat per a l'operativa diària d'agents, no un producte allotjat — el codi resta en privat.
